# Analytical Frameworks

Select from the frameworks below based on the topic. Multiple frameworks may be combined.

| Framework | Best suited for |
|---|---|
| Current state / Challenges / Outlook | Getting an overview of an industry, technology, or social issue |
| Comparative analysis | Comparing options, competitors, or country-level case studies |
| Root cause analysis (Why?) | Understanding problem structure and identifying root causes |
| Trend analysis | Identifying the direction of change and inflection points |
| SWOT / Impact analysis | Supporting decision-making and strategy development |
