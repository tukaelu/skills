# skills

A collection of custom skills for Claude Code to support my day-to-day work.

## Installation

**Using GitHub CLI:**

```bash
# Install all skills
gh skill install tukaelu/skills --agent claude-code --scope user

# Install a specific skill
gh skill install tukaelu/skills smart-commit --agent claude-code --scope user
```

**Using npx:**

```bash
# Install all skills
npx skills add tukaelu/skills -a claude-code -g

# Install a specific skill
npx skills add tukaelu/skills --skill smart-commit -a claude-code -g
```
